# Base Project

A modern web application built with **.NET** and **Angular**, designed with a focus on modularity, security, scalability, and maintainability.

This repository is the starting point for the project and will evolve as the architecture and requirements are defined.

## Project Goals

The project aims to provide a solid foundation for a modern application, with an architecture that can evolve without requiring major changes to existing features.

Some of the main goals are:

- Modular and maintainable architecture
- Secure authentication and authorization
- Clear separation of responsibilities
- Scalable backend structure
- Modern frontend architecture
- Good development practices
- Automated testing
- Logging and error handling
- Configuration management
- Easy maintenance and future expansion

## Current Status

The project is currently in its initial development stage.

The first goal is intentionally simple: create a minimal backend API and validate the basic communication between the frontend and backend before implementing the final architecture.

### Initial Development

The first version will focus on:

1. Create the initial .NET API.
2. Configure the basic application structure.
3. Create a simple user creation endpoint.
4. Receive user data from the frontend.
5. Validate the request.
6. Return a basic success or error response.
7. Create a minimal Angular application to consume the API.

At this stage, authentication, authorization, database integration, tokens, and other infrastructure will not be implemented yet.

These features will be introduced later when the project's definitive architecture is established.

## Future Development
